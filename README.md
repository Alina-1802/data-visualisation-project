# Perfume Sales Dashboard

An interactive Excel dashboard for analyzing perfume sales in a cosmetics store.

## 📊 Description

This project provides the store owner with a clear and accessible interface to monitor key sales statistics, product availability and brand performance. Built in Microsoft Excel, it features dynamic data visualization and automated updates.

## 🧾 Input Data

Two datasets:
- Women's perfumes  
- Men's perfumes  

Each with the following columns:
- `brand`, `title`, `type`, `price`, `sold`, `available`, `lastUpdated`, `itemLocation`, etc.

## 🛠 Dashboard Features

- General statistics: total revenue, number of sold and available items, brand count
- Top 3 brands by:
  - Units sold
  - Revenue
- Pie charts showing:
  - Share of men’s vs women’s perfumes in sales and revenue
- Dropdown menu to select a brand
- Dynamic metrics and charts for the selected brand:
  - Sales and revenue per model
  - Perfume type distribution
- Auto-refresh of pivot tables via VBA macros

## 🧩 Tools & Technologies

- Microsoft Excel  
- Pivot tables  
- Dynamic charts  
- VBA macros for interactivity
